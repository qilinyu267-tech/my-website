# Chic Pet · Pet Fashion Boutique

A boutique pet-fashion brand website designed and developed through human–AI collaboration.

**Live website:** https://chic-pet-boutique.beigeibex11.chatgpt.site

> The hosted website is currently private and may require a ChatGPT sign-in. This repository preserves the website's static source and image assets.

## Project overview

Chic Pet is a Chinese-language concept website focused on stylish clothing, harnesses, leashes, hair bows and accessories for cats, dogs and other small pets. Its visual language combines warm cream, dusty pink and soft brown with minimalist studio product photography.

## What is included

- 32 concept product listings, filtering by pet and collection, and detailed product pages
- Product-only and pet-wearing photos, including real paired image changes for available colorways
- Seasonal and holiday collections
- Brand story, product value and sustainability goals
- Three original editorial Pet Plog stories with dedicated article pages
- Animal welfare initiative explainers and lost-and-found pet information samples
- Responsive layout and a demonstration FAQ chat interface

## Human–AI collaboration

The project owner led brand positioning, target audience, art direction, page structure, feature requirements and iterative quality review. ChatGPT assisted with HTML/CSS/JavaScript implementation, interaction logic, editorial drafts and AI-generated visual concepts. Development involved repeated refinement of image consistency, product-to-pet photo matching, color selection and navigation.

## Run locally

This is a static site. Open `dist/index.html` in a browser, or serve the `dist/` directory using any static HTTP server, for example `python3 -m http.server 8000 --directory dist`.

## Current scope

This is a front-end concept site. Product prices, stock and photos are illustrative. Real payments, verified rescue outcomes, public posting, human customer service and moderation backends are **not** connected. Pet Plog stories are original fictional editorial narratives, and lost-pet cards are labeled examples. Sustainability goals are not presented as certified achievements.

## Project structure

- `dist/index.html` — Home
- `dist/shop.html`, `dist/product.html` — Product catalog and details
- `dist/collections.html` — Collections
- `dist/stories.html`, `dist/story.html` — Plog stories
- `dist/impact.html`, `dist/care.html` — Care initiatives
- `dist/lost.html` — Lost-and-found board
- `dist/values.html`, `dist/about.html`, `dist/help.html` — Brand and support
- `dist/inner.js`, `dist/inner.css` — Shared layout and interactions
